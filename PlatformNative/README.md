# PlatformNative

**Нативная обертка для GLFW, OpenAL и OpenGL на .NET 10**  
С динамической загрузкой, кешированием делегатов и гибридным резолвером.

## 📦 Что внутри?

| Компонент | Описание |
| :--- | :--- |
| **Core/Diagnostics** | Легковесный логгер с уровнями (Error → Trace) и временными метками |
| **Core/Loader** | Кеширующий загрузчик делегатов через `Marshal.GetDelegateForFunctionPointer` |
| **Core/Library/Manager** | Регистрация и управление нативными библиотеками (GLFW, OpenAL) с защитой от рекурсии через `AsyncLocal` |
| **Native/GLFW** | Полная обертка GLFW 3.5.1 (окна, ввод, контекст OpenGL, мониторы) |
| **Native/OpenAL** | Динамическая обертка OpenAL Soft 1.25.2 (загрузка через `alcGetProcAddress`) |
| **Native/OpenGL** | Гибридный резолвер: сначала через `glfwGetProcAddress`, затем прямая загрузка из системы |
| **Host\<T\>** | Lazy-синглтон для управления жизненным циклом библиотек |

## 🚀 Быстрый старт

### 1. Добавьте в проект (через ссылку на .csproj)

```xml
<ItemGroup>
  <ProjectReference Include="..\PlatformNative\PlatformNative.csproj" />
</ItemGroup>
```

### 2. Инициализация

```csharp
// Инициализируем GLFW
if (!GLFW.Initialize())
{
    Console.WriteLine("Не удалось загрузить GLFW");
    return;
}

// Инициализируем OpenGL (через GLFW)
if (!OpenGL.Initialize())
{
    Console.WriteLine("Не удалось загрузить OpenGL");
    return;
}

// Создаем окно
IntPtr window = GLFW.glfwCreateWindow(800, 600, "Hello World!", IntPtr.Zero, IntPtr.Zero);
GLFW.glfwMakeContextCurrent(window);
```

### 3. Загрузка звука через OpenAL

```csharp
if (OpenAL.Initialize())
{
    // Создаем буфер
    OpenAL.AlGenBuffers(1, out uint buffer);
    
    // Загружаем WAV-данные (пример)
    // OpenAL.AlBufferData(buffer, OpenAL.AL_FORMAT_MONO16, data, size, freq);
    
    // Создаем источник
    OpenAL.AlGenSources(1, out uint source);
    OpenAL.AlSourcei(source, OpenAL.AL_BUFFER, (int)buffer);
    OpenAL.AlSourcePlay(source);
}
```

## 🧠 Архитектурные фишки

### 1. Гибридный резолвер OpenGL
Сначала пытается получить указатель через GLFW (для корректной работы с контекстом), а если не вышло — лезет напрямую в системную библиотеку (`opengl32.dll` / `libGL.so`). Это гарантирует работу даже без GLFW.

### 2. Защита от рекурсивных вызовов
В `Manager` используется `AsyncLocal<bool> IsResolving`. Если библиотека пытается разрешить функцию внутри своего же резолвера — возвращается `IntPtr.Zero` без бесконечного цикла.

### 3. Динамическая загрузка OpenAL
Функции AL загружаются через `alcGetProcAddress`, а не через статические `[DllImport]`. Это делает обертку совместимой с любыми реализациями OpenAL (включая встроенные в ОС).

### 4. Кеширование делегатов
Каждая загруженная функция сохраняется в `Dictionary<string, Delegate>`. Повторные вызовы `LoadFunction<T>` возвращают кешированный делегат без повторного обращения к нативной библиотеке.

## 📚 Используемые версии

- **.NET 10** (с поддержкой NativeAOT через `[RequiresDynamicCode]`)
- **GLFW 3.5.1** (официальный C-API)
- **OpenAL Soft 1.25.2** (или любая совместимая реализация)

## 🛠️ Требования к системе

| ОС | Библиотеки |
| :--- | :--- |
| **Windows** | `glfw3.dll`, `soft_oal.dll` (или `openal32.dll`) |
| **Linux** | `libglfw.so.3`, `libopenal.so.1` |
| **macOS** | `libglfw.3.dylib`, `libopenal.1.dylib` |

> Библиотеки должны лежать в папке с исполняемым файлом или в системном `PATH`.
